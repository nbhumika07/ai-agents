# AI Labs & Agent Projects

Welcome to the repository containing various AI labs, assistant applications, and autonomous agent implementations.

---

## 📁 Project Directory

* **`Simple ai agent/`**
  Contains basic rule-based assistant implementations built with Python conditional logic and interactive user inputs.

* **`ai-personalized-study-planner/`**
  Implements study assistant agents utilizing advanced prompt engineering techniques including zero-shot, few-shot, and role prompting.

* **`college-library-chatbot/`**
  A Retrieval-Augmented Generation (RAG) assistant designed to answer student questions accurately using college documents, handbooks, and FAQs.

* **`shortfilm/`**
  Workspace dedicated to multimedia scripting, scene organization, and creative narrative development assets.

* **`travel-agent/`**
  An autonomous mini travel agent featuring tool execution, memory management, dynamic re-planning, and human-in-the-loop safety approvals.
