# College Library Chatbot 

This is a simple Python chatbot that I made as a college project to help students find books in a library.

The chatbot runs in the terminal and uses a JSON file (`books.json`) to store the library book details.

## What it can do

- Search for books
- Find books by author
- Find books by category
- Check whether a book is available
- Show all the books in the library
- Understand simple questions like:
  - "Do you have Python books?"
  - "Who wrote Clean Code?"
  - "Is Atomic Habits available?"
  - "Books on machine learning"

## Technologies Used

- Python
- JSON

## Files

- `library_chatbot.py` - Main chatbot program
- `books.json` - Contains the library book details
- `README.md` - Project information
- `.gitignore` - Files that are not uploaded to GitHub
